# Vaihingen Semantic Segmentation

Team integration project for urban semantic segmentation using the ISPRS Vaihingen dataset and the supplied RSSS_code structure based on UNetFormer.

## Team workspaces

| Workspace | Main responsibility | Deliverables |
| --- | --- | --- |
| P1/ | Data preparation | Data access instructions, preprocessing, and partition records |
| P2/ | Model implementation and training | Model code, training configurations, and run summaries |
| P3/ | Experimental evaluation | Baseline and controlled comparison, metrics, and visual results |
| P4/ | Project integration and reporting | Integration notes, report contributions, and presentation materials |
| final/ | Shared integrated deliverable | Reviewed code, evaluation outputs, and presentation materials |

Members will be assigned to P1–P4 by the team. Keep the Canvas-name/GitHub-account identity mapping in the private Canvas PDF.

## Working together

Work in the assigned folder and use a separate branch for each change. Open a pull request when the work is ready for team review. Put reviewed shared deliverables in final/.

Download datasets separately from the official provider. Keep datasets, model weights, credentials, and the private Canvas proposal outside the public repository. Record data access and environment setup instructions as implementation progresses.
